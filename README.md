# Call Easy - Mobile Candidate & Admission Outreach Web App

Call Easy is a mobile-first single-page web application designed for fast, one-handed calling and automatic post-call follow-ups via WhatsApp and Email.

## Features
- **Mobile-Optimized Interface**: Big touch targets designed for one-handed operation.
- **Desktop Simulator**: Fullscreen notification on desktop with an interactive mobile simulator.
- **1-Tap Call & Auto Follow-up**: Initiates phone calls and automatically triggers WhatsApp & Email follow-up prompts upon return.
- **Pre-filled Message Templates**: Customizable WhatsApp and Email templates featuring admission hotline `8122280223`.
- **Progress Tracking**: Saved state in `localStorage` with a candidate queue drawer and search/filters.

## Quick Start
Open `index.html` in any web browser or serve locally using:
```bash
npx http-server -p 8080
```
Then access `http://localhost:8080` or `http://<your-local-ip>:8080` on your mobile phone.
