Twilio & API Setup Guide

🔗 Backend Server URL (For Twilio Masked Calls)

Enter your ngrok or deployed backend server URL to place anonymous calls from your mobile phone:

1. Twilio Account SID & Auth Token

Copy your Account SID & Auth Token from your Twilio Console into your .env file under TWILIO_ACCOUNT_SID and TWILIO_AUTH_TOKEN.

2. Virtual Phone Number (Caller ID)

Buy a Twilio virtual phone number in your console (~$1.15/mo) and set TWILIO_PHONE_NUMBER in .env. This number is shown to candidates so your personal number is never exposed!

3. Recruiter Personal Number

Set RECRUITER_PHONE_NUMBER in .env. When you tap "Call Candidate", Twilio calls your phone first, and when you answer, bridges you to the candidate.

4. Public Webhook (ngrok for Local Testing)

Twilio Voice needs a public endpoint to fetch call bridging XML (TwiML). When testing locally, run npx ngrok http 3000 and set SERVER_BASE_URL in .env to your ngrok URL.

5. WhatsApp & Email Auto Follow-up

Use Twilio WhatsApp sandbox (whatsapp:+14155238886) or a production WABA. For Email, configure your Gmail App Password or SMTP credentials in .env.
